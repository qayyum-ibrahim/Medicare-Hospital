# Meridian Care Hospital (prototype)

A demo-ready prototype of a revenue-cycle and patient-flow web app for a **fictional** private hospital in Lagos, Nigeria.

**Demo: fictional data only.** Every external integration (HMO, NHIA, WhatsApp, lab devices) is simulated and labelled "Simulated". Prices are illustrative, not real tariffs.
